# DummyMod: ИИ и строительство

Minecraft Fabric 1.21.11. Требуется установленный patched Baritone с контекстом на каждую сессию.

Right Shift открывает AltManager. Кнопка **ИИ / OmniRoute** находится снизу слева.
В меню ИИ доступны **Движение**, **Полёт** и **Проекты / память**.
В белый список нужно внести точный Minecraft-ник (несколько ников разделяются запятыми).
Пустой список запрещает ответы всем. Настройки применяются после нажатия «Сохранить».

URL API: `https://omni.afternet.my/v1`. Проверенная модель: `agy/gemini-3.8-flash-high`.
Ключ хранится отдельно в `config/dummymod-ai.json`, с правами 0600, и не входит в JAR.
Сохранённый ключ не показывается в меню; пустое поле оставляет его прежним.

В чате напишите `НикДамми, построй ...`. Если дамми одна, можно говорить без обращения.
После обращения к одной из нескольких дамми последующие реплики поступают ей в течение
30 минут. Другие игроки игнорируются. Поддерживаются штатные сообщения с профилем игрока
и серверные форматы `<Nick> сообщение`, `[G] [VIP] Nick: сообщение`, `Nick » сообщение`.
Опцию «Чат сервера» можно отключить для использования только сообщений с отдельным отправителем.

Модель создаёт собственный проект из блоков, прямоугольников, полых коробок, эллипсоидов
и цилиндров. Можно обсудить размер, материалы, стоимость и место, попросить переделать
проект. Мод сам считает материалы. Новый проект ожидает команды `строй`.
Ресурсы бросаются рядом с дамми: она подбирает нужные предметы в пределах 10 блоков.
Строительство идёт партиями до 128 ячеек; материалы можно приносить постепенно.
В выживании размер партии учитывает имеющиеся материалы: дамми начинает с того,
что уже есть, а не требует сначала наполнить целую партию.
Команды `пауза`, `стоп`, `продолжай` обрабатываются немедленно, даже во время запроса к модели.
Доступны также разговорные команды идти, следовать, прыгнуть, добыть и снести указанную область.
Защита территории и правила сервера могут препятствовать этим действиям.

В настоящем серверном creative дамми использует отдельное строительство с полётом,
без служебных опор, и сама берёт нужный блок в творческий инвентарь. Можно написать
`НикДамми, строй в креативе`. Полёт не меняет серверный режим игры: creative должен
быть у аккаунта дамми. Фундамент и соседние блоки остаются нужны для обычного размещения.
Перед установкой блоков creative-исполнитель расчищает мешающие ячейки проекта сверху
вниз, а строит снизу вверх: он не пытается достать засыпанный фундамент через грунт.
Если модель описала только засыпанный фундамент, исполнитель также снимает до 16
блоков естественного грунта над его ячейками в пределах площадки. Посторонние постройки
при такой подготовке не разбираются. Для установки дамми отлетает, если закрывает ячейку
своим телом; трава не перекрывает видимость твёрдой опоры.
Каждое действие ожидает подтверждения сервера для мира этой дамми. Предсказанный
локально блок не засчитывается как готовый до подтверждения; повторный отказ
заставляет сменить позицию. Откат коллизий также использует игрока этой дамми,
чтобы фоновые аккаунты не получали координаты основного игрока.
Установка выполняется без дополнительной паузы между подтверждёнными действиями,
до одного блока за игровой тик. На свободных длинных участках дамми бежит, а
перед установкой и поворотами замедляется. Скорость также зависит от пути и ответа сервера.
По умолчанию дамми ходит по доступной поверхности, летает для подъёма или обхода и
снова отключает полёт при наличии опоры. Кнопка «Движение: полёт» разрешает постоянный
полёт. Команды `летай быстро`, `летай с бегом`, `летай медленно`, `летай без бега`,
`летай авто` задают скорость; возле блока любой режим замедляется для точной установки.
Для расчистки выбирается самый быстрый подходящий инструмент из собственного инвентаря.
Устаревший блок `minecraft:chain` в схемах преобразуется в `minecraft:iron_chain`,
который зарегистрирован в Minecraft 1.21.11.
Если написать `выдавай себе материалы через give`, разрешается автоматическая выдача
себе необходимых блоков по одному стеку. Сервер должен предоставить дамми команду
`/give`; выбор других игроков, селекторы и произвольные команды не допускаются.
Получение стека отслеживается отдельно от его расходования, поэтому после полного
расхода дамми может запросить следующую порцию. Неподтверждённая выдача не повторяется.
`без креатива`, `выключи give` отключают соответствующие режимы.

Если строительство не продвигается, дамми сама пересчитывает путь, пробует другой
подход и уменьшает проблемную партию. После четырёх безуспешных восстановлений
сообщает точку проблемы и сохраняет проект на паузе. Ожидание ресурсов не считается
застреванием. Завершение подтверждается проверкой блоков в мире.

OmniRoute использует SSE, HTTP/1.1 и до трёх попыток при временных сетевых ошибках,
перегрузке, HTTP 429/5xx, пустом HTTP 400 и сбое прокси провайдера. Повреждённый JSON
не применяется к стройке; запрос повторяется в пределах тех же трёх попыток.
Ошибочные ключи/модели не повторяются.
Оригинальные 300 сообщений остаются в истории; для Gemini соседние реплики одной роли
объединяются в один запросный ход. Стоп отменяет HTTP-запрос, а отказ API не останавливает
согласованную стройку. Код и краткая причина ошибки теперь попадают в лог.

Диагностика управления выключена по умолчанию; для подробного отладочного лога есть
JVM-флаг `-Ddummymod.controlDiagnostics=true`. При наличии Sound Physics Remastered
после переключения аккаунта обновляется кэш мира, чтобы избежать null в звуковом потоке.
Причины отключения дамми записываются в лог.

Память хранит последние 300 сообщений пользователя и дамми на диске отдельно для
сервера, дамми и разрешённого ника. Проект сохраняется отдельно, с привязкой к измерению.
При замене схемы незаконченный проект остаётся в архиве. `сохрани проект` сохраняет
схему в архив вручную. **Проекты / память** позволяет выбрать прежний проект для
продолжения; «Очистить чат» удаляет переписку и сохраняет схемы. Текущая схема отмечена
в списке; подсказка показывает её координаты и время сохранения. После переподключения
текущий проект можно продолжить командой `продолжай`. Уже построенные блоки определяются
по миру, поэтому перезапуск не сбрасывает фактический прогресс. Независимые экспорты
в `config/dummymod-ai-saved-projects` также загружаются для соответствующего владельца.
На сетевом сервере сами блоки сохраняются сервером; локальный архив содержит схему и
координаты для продолжения. Большие постройки нужно разбивать
на части: один проект до 96 блоков по оси, 50000 ячеек и 1024 операций.

В меню прокси маршруты назначаются по числу живых и подключающихся аккаунтов.
Равные нагрузки чередуются; отключённые аккаунты освобождают маршрут. Уже открытые
соединения не переезжают. «Direct + SOCKS5» включает прямой маршрут в балансировку,
«Только SOCKS5» требует хотя бы одного включённого прокси и не переключается на Direct
при его отказе. Прокси должен быть доступен и разрешать соединение с сервером.

Сборка и проверки: `./gradlew build`. `verifyAi` проверяет историю, права чата,
геометрию, сборку SSE, распределение маршрутов и удержание Minecraft-логина до SOCKS5 CONNECT.
Необязательный `clientProbeJar` собирает отдельный мод для запуска GUI/API/creative/survival проверки
в тестовом клиенте; он не входит в обычный DummyMod и не устанавливается в PrismLauncher.
С `-Ddummymod.probePlan=/absolute/path/project.json` проверка строит большую сохранённую
схему на отдельном тестовом сервере и восстанавливает её с диска после частичного выполнения.

При замене JAR в PrismLauncher уже работающий Minecraft продолжает использовать старый
код. Для загрузки новой версии нужно закрыть игру полностью и запустить этот экземпляр заново.
